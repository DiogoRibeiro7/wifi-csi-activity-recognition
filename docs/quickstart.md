# Quickstart

This guide uses the current CLI and a tiny synthetic dataset so you can verify the install without needing hardware first.

## 1. Install the package

Use the editable install for local work:

```bash
pip install -e .[dev,docs]
```

If you want to train or run inference, install a compatible PyTorch build for your platform.

## 2. Create demo arrays

```bash
python - <<'PY'
import numpy as np

rng = np.random.default_rng(42)
data = rng.random((24, 1, 8, 8), dtype=np.float32)
labels = rng.integers(0, 2, size=24, dtype=np.int64)

np.save("demo_data.npy", data)
np.save("demo_labels.npy", labels)
PY
```

## 3. Train a small model

```bash
python -m wifi_activity_recognition.cli train \
  --data demo_data.npy \
  --labels demo_labels.npy \
  --model cnn2d \
  --hardware esp32 \
  --epochs 1 \
  --batch-size 4 \
  --output demo_model.pt
```

Expected output includes dataset loading, training progress, and a saved model artifact.

## 4. Evaluate the trained model

```bash
python -m wifi_activity_recognition.cli evaluate \
  --model demo_model.pt \
  --data demo_data.npy \
  --labels demo_labels.npy \
  --hardware esp32
```

The command prints accuracy, precision, recall, and F1 score for the test split generated by `Dataset.from_files(...)`.

## 5. Inspect the environment

```bash
python -m wifi_activity_recognition.cli info --hardware all
```

This reports the currently registered hardware drivers and available model metadata.
